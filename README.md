### 🤖 iCAM — Assistive On-Device Vision AI

[![Android APK](https://img.shields.io/badge/📱_Android_APK-Download_iCAM-3DDC84?style=for-the-badge&logo=android&logoColor=white)](https://github.com/naeemnaikwadi)

</div>

> **Stack:** Python · TensorFlow · Keras · TFLite · OpenCV · Android

A **fully offline assistive AI app** for visually impaired users — classifying 14 FMCG categories in real-time.

| Metric | Result |
|:-------|:-------|
| 🎯 Validation Accuracy | **94.4%** (peak) |
| ⚔️ vs MobileNetV2 | **+5.3 pp** better accuracy at **3.5× smaller** model size |
| 📦 Model Size | **4 MB** vs 14 MB |
| ⚡ Inference Latency | **~163 ms** (22% faster) |
| 🗂️ Dataset | 3,829 self-curated images · 14 FMCG classes |
| ♿ Accessibility | Real-time TTS + Haptic feedback · fully offline |
| 📝 Research | Manuscript in preparation for journal submission |
