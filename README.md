A comprehensive **10-role ERP platform** covering the full lifecycle of an educational institution — from admissions to exams to library to hostel management.

| Feature | Details |
|---------|---------|

| 📊 Data Analytics | Attendance, participation & academic data analytics via MongoDB Atlas |
| 📱 Deployment | Cross-device PWA deployed on Vercel + Render |

### 🤖 iCAM — Assistive On-Device Vision AI
[![Download](https://img.shields.io/badge/📱_Android_APK-Download_iCAM-3DDC84?style=for-the-badge&logo=android)](https://github.com/naeemnaikwadi)

</div>

A **fully offline assistive AI app** for visually impaired users — classifying 14 FMCG product categories in real-time on-device.

| 🗂️ Dataset | 3,829 self-curated images, 14 FMCG classes |
| ♿ Accessibility | Real-time TTS + Haptic feedback, fully offline |
| 📝 Research | Manuscript in preparation for journal submission |
